# Printing

Printer: Creality Ender 3 Pro, sliced in Creality Print. Material: PETG.

**Default settings** (adjust per part below once tested)

| Setting | Value |
|---|---|
| Layer height | 0.2 mm |
| Walls | 4 |
| Infill | 20 % gyroid |
| Heat-set inserts | M2, pressed in with the soldering iron |

**Per-part log**: fill in as parts get printed.

| | | | | | |

Print files (`.stl` / `.3mf`) are generated from `hardware/cad/` and are not committed. Rerun the CAD script to regenerate them. Attach a final print set to a GitHub Release when a version is done.
