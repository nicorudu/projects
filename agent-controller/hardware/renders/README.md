# Renders

One folder per design revision, named `YYYY-MM-DD-revN-short-name`. Files inside are numbered in viewing order (`01-…png`).

- Renders come from the CAD script in `hardware/cad/<rev>/`. Rerunning that script reproduces them.
- Never overwrite an older revision. Make a new folder, so the history stays visible.
- Photos of real hardware go in `media/photos/YYYY-MM-DD-what.jpg`, not here.
