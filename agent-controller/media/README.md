# Media

| Folder | What | Naming |
|---|---|---|
| `photos/` | Real photos: parts arriving, breadboard, prints, assembly | `YYYY-MM-DD-what.jpg`, e.g. `2026-11-18-parts-arrived.jpg` |
| `web/` | Small, cropped versions of renders and photos for the website and social posts (WebP, 1200 px wide) | Same name as the source, e.g. `rev2-01-docked-open.webp` |

Videos are not committed. Upload them to YouTube or X and add the link to the build log entry.

Keep photos under about 1 MB each; resize phone photos before committing.
